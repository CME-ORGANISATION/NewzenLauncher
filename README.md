# Newzen Launcher

Newzen Launcher est un launcher Minecraft personnalisé basé sur [HeliosLauncher](https://github.com/dscalzi/HeliosLauncher), conçu pour offrir aux joueurs une expérience simple, moderne et fluide.

Le launcher permet de gérer la connexion aux comptes Minecraft Microsoft, de télécharger automatiquement les fichiers nécessaires au jeu, de vérifier les fichiers du client et de lancer Minecraft depuis une seule application.

### Fonctionnalités
- Interface personnalisée aux couleurs de Newzen.
- Authentification Microsoft pour les comptes Minecraft officiels.
- Installation et mise à jour automatiques des fichiers du jeu.
- Gestion de Java et des paramètres de lancement.
- Configuration du client et des mods selon le serveur.
- Actualités et informations du serveur.
- Génération d'un installateur Windows.

### Technologies
- Electron
- Node.js
- HTML, CSS et JavaScript
